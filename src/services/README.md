# Serviços externos

Coloque aqui os módulos que conversam com serviços externos, como o futuro envio de e-mail. As páginas importam esses módulos, evitando misturar integração com interface.

Ainda não há serviço de e-mail configurado nem dependência de EmailJS instalada. Não simule envio bem-sucedido. Chaves privadas nunca devem ir para o front-end; variáveis VITE_* são públicas no navegador.
