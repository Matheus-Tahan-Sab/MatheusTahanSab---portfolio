# Sprites Pokémon

Sprites estáticos de Swampert (#260), Lucario (#448) e Gengar (#094), obtidos de https://github.com/PokeAPI/sprites em 13/10/2026.
Origem: sprites/pokemon/versions/generation-v/black-white/{260,448,94}.png (estilo dos jogos Black/White).
Pokémon e personagens pertencem aos respectivos titulares (Nintendo / Creatures / GAME FREAK). A PokéAPI reúne as imagens; não é autora dos personagens.
As animações do portfólio são CSS, permitindo pausa e preferência de movimento reduzido. Nenhuma chamada à API é necessária para carregar os personagens.
