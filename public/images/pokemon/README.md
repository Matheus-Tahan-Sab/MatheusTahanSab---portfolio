# Sprites Pokémon

Os sprites de caminhada usados no site vêm de https://github.com/PMDCollab/SpriteCollab, obtidos em 13/10/2026:
- Swampert: `sprite/0260/Walk-Anim.png`, 32×48 por quadro, quatro quadros.
- Lucario: `sprite/0448/Walk-Anim.png`, 32×48 por quadro, quatro quadros.
- Gengar: `sprite/0094/Walk-Anim.png`, 32×40 por quadro, quatro quadros.

Cada arquivo é preservado integralmente; o CSS seleciona os quadros, com escala 2× e direções leste (linha 2) e oeste (linha 6). Metadados `AnimData.xml` e registros de créditos estão incluídos ao lado das imagens. Os registros atribuem os sprites originais de caminhada a CHUNSOFT; Swampert também tem contribuições registradas de PMDCollab (identificador 356635814668664832). Pokémon e personagens pertencem aos respectivos titulares Nintendo / Creatures / GAME FREAK; PMDCollab reúne os recursos.

As poses estáticas anteriores da PokéAPI permanecem arquivadas nestas três imagens: swampert.png, lucario.png, gengar.png. Origem https://github.com/PokeAPI/sprites, `sprites/pokemon/versions/generation-v/black-white/{260,448,94}.png`.

Animações CSS respeitam pausa e movimento reduzido; não requerem API externa.
